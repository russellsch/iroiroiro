# Version 0.1.1 candidate verification

Version 0.1.1 is a local VSIX candidate. The version change lets VS Code install it as an update to 0.1.0. Runtime behavior is unchanged.

The package check log is `artifacts/build-0.1.1.log`. The candidate and its checksum are in `artifacts/iroiro-iro-0.1.1.vsix` and `artifacts/SHA256SUMS`.

The [0.1.0 record](0.1.0.md) and [requirement results](0.1.0.csv) provide the previous verification baseline. They do not establish new host or release results for 0.1.1. The remaining platform, visual, performance, upgrade, and publication checks stay open.

Details and Changelog rendered from the 0.1.0 VSIX in a clean, regular VS Code profile. The blank-page issue reported in an existing profile remains unresolved. This candidate does not claim a fix for that issue.
